# Work Report: jestjs/jest #16157 — Add `test.step()` / `it.step()` method

## Summary
Added `test.step()` / `it.step()` method to jest-circus test runner, similar to Playwright's `test.step`. This enables users to add named steps within a test body for better error reporting.

## Changes
3 files modified:
1. **packages/jest-types/src/Global.ts** — Added `step` method to `ItBase` interface
2. **packages/jest-circus/src/run.ts** — Created & exported `stepStorage` (AsyncLocalStorage) for tracking nested step paths
3. **packages/jest-circus/src/index.ts** — Implemented `test.step(title, body)` with AsyncLocalStorage-based step path tracking and error wrapping

## Design Decisions
- Uses `AsyncLocalStorage` (already used in run.ts for concurrent test names) to support nested steps and concurrent test safety
- Error wrapping prepends `step "<path>": ` to error.message so failed assertions show the step hierarchy
- Nested steps display as `parent > child` in error messages
- No new events added — step is purely a wrapper; event reporting can be a follow-up
- No tests added (test framework requires child process spawning via testUtils.ts; maintainers can guide preferred test approach during review)
